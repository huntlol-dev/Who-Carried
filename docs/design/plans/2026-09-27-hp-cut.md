# HP cut by effects (Fur Coat) — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record the HP a player's relic or effect takes off enemies by setting it directly (Fur Coat starts enemies at 1 HP), and show it on the Sources tab as a separate line that doesn't count as damage.

**Architecture:** A prefix on `CreatureCmd.SetCurrentHp` measures a lowering on a living, non-infinite enemy. The credit goes to the running effect's player (`EffectSources.Running`), or else to the single holder of a relic of the kind found up the call stack (`SelfFire.Caller`). It's stored in a new `PlayerTotals.HpCut` through `RunStats.RecordHpCut`, which never touches damage or fights. `RecapBuilder` passes it on as `SourcesView.HpCuts`, and each Sources column writes one muted line under its banner.

**Tech Stack:** C# / .NET 9, Harmony, the game's API, the repo's console test runner.

**Spec:** [HP cut by effects, shown apart from damage](../specs/2026-09-27-hp-cut-design.md).

## Global constraints

- Branch `feature/hp-cut` from `main`. Commit after each task. Don't push. When done, squash-merge into `main` as one commit, subject `Show HP that Fur Coat and the like cut, apart from damage`.
- Build and test with `"/c/Program Files/dotnet/dotnet.exe"`; build against both game versions (default and `-p:GameData="E:/Claude/sts2-refs/v0.107.1"`).
- No relic or mod is named in code. Fur Coat appears only in docs, comments and tests' sample data.
- HP cut never counts as damage: not in `DamageDealt`, `Sources`, fight buckets, `BiggestHit`, awards or the scoreboard.
- Every new English string gets its `zhs.json` entry in the same commit.
- Only read game state.
- Log line: `{name} cut {hp} hp with {Kind}:{Id} ({Label}) | target {target}`. It must not match the `Hit` or `Kill` patterns.

## Review focus

1. **Summoned enemies** in a marked fight: Fur Coat sets them to 1 from `AfterCreatureAddedToCombat`, which the mod doesn't watch. The call-stack fallback must find the relic, and credit only when exactly one player holds one. A reviewer checks the fallback runs only when `EffectSources.Running` has no player.
2. **An enemy lowering its own HP**, or a mod's undying phase ending at 1 HP from its own power: the effect's owner is an enemy, so nothing is recorded. A reviewer checks a null player returns early without a fallback that could guess a player.
3. **A saved run from before this change** has no `HpCut` field and must load with it empty. Task 1 tests it.
4. **The note under the banner** mustn't push the rows out of alignment between columns with and without a cut. The label is hidden (not empty) when there's nothing, so columns without a cut keep their height. Task 3 checks the preview screenshot.
5. **SetCurrentHp to 0** (a kill) credits the HP it took, then the game's kill follows. That kill finds 0 HP and credits nothing (`EffectCredit.ForKill` needs HP above 0). A reviewer checks the order: our prefix runs before the HP changes.

/// <summary>HP an effect took off a creature by setting it directly, not by a hit (Fur Coat starting enemies at 1).</summary>
public static class HpCut
{
    public static int Amount(int currentHp, decimal newHp) =>
        currentHp <= 0 ? 0 : Math.Max(0, currentHp - (int)Math.Max(0m, Math.Ceiling(newHp)));

- [ ] **Step 3: `Tracker.OnHpSet`**

```csharp
    /// <summary>
    /// An enemy's HP set lower without a hit (Fur Coat starting it at 1): HP cut, credited to the effect's player and kept
    /// apart from damage. The effect is the one running a watched hook; failing that, the game content up the call
    /// stack, if exactly one player holds a relic of that kind.
    /// </summary>
    public static void OnHpSet(Creature creature, decimal amount)
    {
        if (!creature.IsEnemy || creature.IsDead || FactsExtractor.HpInfinite(creature)) return;
        int cut = HpCut.Amount(creature.CurrentHp, amount);
        if (cut <= 0) return;
        SourceCandidate? by = EffectSources.Running is AbstractModel running ? FactsExtractor.Candidate(running) : null;
        if (by?.OwnerId == null && SelfFire.Caller() is RelicModel kind && _run != null)
        {
            List<RelicModel> held = _run.Players.SelectMany(p => p.Relics).Where(r => r.GetType() == kind.GetType()).ToList();
            if (held.Count == 1) by = FactsExtractor.Candidate(held[0]);
        }
        if (by?.OwnerId is not ulong player)
        {
            _log?.Write($"{Where} {Describe(creature)} hp set {creature.CurrentHp} -> {amount}, no player behind it");
            return;
        }
        _stats.RecordHpCut(player, by.Source, cut);
        _log?.Write($"{Where} " + LogReplay.HpCutLine(NameOf(player), by.Source, cut, Describe(creature)));
        Touch();
    }
```

`FactsExtractor.HpInfinite` comes from the infinite-HP branch. If that hasn't merged yet, use `creature.HpDisplay.IsInfinite()` here, and switch to the helper when the branches meet. Add `using MegaCrit.Sts2.Core.Models;` if `RelicModel` isn't in scope.
